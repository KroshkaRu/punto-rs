# Готовая статистика Smart

Таблицы рассчитаны один раз скриптом `scripts/build-smart-stats.py`. Cargo и приложение этот скрипт не запускают.

Каждое уникальное слово из статей `.dic` приводится к нижнему регистру. Флаги Hunspell и поля морфологии отбрасываются; словоформы по `.aff` не разворачиваются. В статистику входят буквенные слова A–Z и А–Я/Ё без внутренней пунктуации и цифр. Для слова длины n учитываются все n−2 перекрывающиеся тройки, включая повторы.

Вес тройки: `ln((count + 1) / (total + 33³))`. Одинаковая область сглаживания для двух языков не даёт английскому преимущества из-за меньшего алфавита. Таблица содержит тройку, число вхождений и готовый вес; для отсутствующих троек задан отдельный вес.
